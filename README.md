# SQL Data Warehouse & Analytics Project

## Overview

This project demonstrates the end-to-end development of a modern SQL Data Warehouse solution using a Medallion Architecture (Bronze, Silver, and Gold layers).

The project analyses clean ERP and CRM data into a from data warehouse project to  analytics-ready data warehouse that supports business reporting, exploratory data analysis, and advanced analytics.

The solution includes:

- Data ingestion
- Data cleansing
- Data transformation
- Data modeling
- Dimension and fact table creation
- Exploratory Data Analysis (EDA)
- Business reporting
- Customer segmentation
- Performance analytics
